# Invoiceflow

Multi-tenant accounting and invoicing for small businesses. UAE first, Android first.

## Repository layout

```
apps/
  api/       NestJS backend (TypeScript)          — Sprint 0
  mobile/    Flutter Android/iOS app              — Sprint 0
  admin/     Next.js Super Admin portal           — Sprint 0
packages/    Shared code (e.g. generated API client)
docs/        Product and technical documentation
  adr/       Architecture decision records
```
