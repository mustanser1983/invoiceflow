# Invoiceflow mobile (Flutter)

## First-time setup

The Android project folder (`android/`) is generated by Flutter and is not committed yet. With the Flutter SDK installed:

```bash
cd apps/mobile
flutter create . --platforms=android --org ae.invoiceflow --project-name invoiceflow
rm test/widget_test.dart
flutter pub get
```

`flutter create .` only adds missing files; it does not overwrite `lib/` or `test/`. It does add a template `test/widget_test.dart` for a counter app, which is why the second line deletes it. Commit the generated `android/` folder afterwards (signing keys stay out of git; see `.gitignore`).

## Run

```bash
flutter run --dart-define-from-file=config/dev.json
```

`config/*.json` hold non-secret build settings only (environment name, API URL). Replace the `example.invalid` URLs once staging and production domains exist.

## Check

```bash
flutter analyze
flutter test
```
